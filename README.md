Plataforma-De-Ride-Sharing-uber-like-

Una página donde una persona pueda pedir un viaje y un conductor disponible pueda aceptar la solicitud. También queremos que exista la posibilidad de compartir un viaje cuando dos personas tengan una ruta parecida.

1) Matching dinámico entre conductores y pasajeros : 
El sistema se encarga de buscar un conductor disponible y que esté cerca del pasajero. Para esto, se puede tener en cuenta la ubicación del conductor y del pasajero.

2) Sistema de tarificación dinámica : 
El precio del viaje puede cambiar dependiendo de la distancia, el tiempo del recorrido y la cantidad de pasajeros que estén solicitando el servicio. Por ejemplo, si hay muchos pasajeros solicitando viajes, pero pocos conductores disponibles, el precio podría aumentar.

3) Gestión de pagos y propinas : 
El sistema puede manejar varias opciones de métodos de pago, como, por ejemplo: efectivo, transferencia o pago electrónico. Esto se realizaría al momento de finalizar el viaje. También se podría agregar la opción de dejar una propina al conductor.

4) Sistema de seguridad y emergencias : 
Aquí se puede manejar la seguridad tanto del conductor como del usuario, permitiendo visualizar los datos del conductor y del vehículo, y guardar la información del viaje. También se pueden guardar algunos datos personales del usuario. Además, se puede incluir un número  de emergencia para situaciones en las que se necesite ayuda.
