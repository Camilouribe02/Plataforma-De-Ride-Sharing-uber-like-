# RideShare — mismo diseño, lógica de mapas mejorada

Esta versión conserva el `dashboard.php` y `assets/style.css` del proyecto base para no cambiar el diseño visual del dashboard ni el login.

Se actualizó únicamente `assets/app.js` para mejorar el comportamiento del mapa: autocomplete desde la primera letra con sugerencias rápidas, búsqueda remota de lugares en Santander, selección de destino, ruta, distancia, tarifa, vehículo y pago.
